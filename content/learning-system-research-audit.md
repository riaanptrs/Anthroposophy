All existing authored Markdown documents were scanned for headings, dates, links, source references and topic coverage; current source audits, reference material and relevant course/lecture records were read closely. ## Publication and rendering boundaries

No explicit repository `LICENSE` file was located. The user’s site-revision request authorizes reuse of existing original teaching and research notes; it does not establish a licence for distributing complete modern book translations. Steiner’s German writings and modern English translations have different provenance. Preserve translator/edition credit and the short-excerpt boundaries already used in the course.

The meditation course contains five complete selected modern English verses and separately authored Foundation Stone study translations. A new research library should link the attributed meditation sessions rather than duplicate those full selected verses into additional notes. The source review is useful public analysis; a private anthology is not a public library download. Ancient Myths and the meditation anthologies have source descriptions in their reviews but no corresponding fingerprinted entries in the current source register; report that distinction honestly.

Generate public HTML notes from the authored Markdown with searchable titles, summaries, headings and note text. Add filters for source/book, theme, document kind, current/history status and note language. Preserve meaningful tables and source attributions, and add a short contents list for long documents. Keep bibliography-only suggestions visibly separate from reviewed teaching.

For each rendered link, resolve its original repository destination first. Rewrite Markdown-note links to research HTML; rewrite existing `docs` links to actual website routes; preserve explicit language partners and verify anchors. The original cleaned self/world illustration may be included with its adaptation/provenance label if used. Full books, private attachments and ignored OCR/transcripts must not be indexed, copied or offered as downloads.

Research navigation and summaries can be bilingual while source notes retain their actual language. Most analysis is English; some historical notes include bilingual drafts. Label this honestly instead of implying that every research body has already been translated. Current source notes should be easy to discover; technical implementation history can remain behind an archive filter. This preserves the deep library while allowing the beginner pathway to become the dominant entry.
