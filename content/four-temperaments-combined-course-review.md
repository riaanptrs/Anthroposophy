# Review of the combined temperament course against the new book capture

The new 23-page PDF and Markdown contain the Berlin lecture of 4 March 1909, GA 57, in the B. Kelly translation revised by Matthew Barton. The publication is Rudolf Steiner Press / Sophia Books, 2012; the translation revision is dated 2008. This review is scoped to the twelve-lesson `understanding-temperaments` course. It recommends six source additions, four source-concept checks and corrected edition/page references, while retaining the original continuing case, practice, transfer questions and Childs/Mystery comparisons.

The machine-readable draft is `.sources/four-temperaments-2026-review/combined-course-draft.json`. It contains `proposals`, `sourceChecks`, `readingMap`, `passages` and the explicit IDs to preserve. It is a proposal file, not a replacement for any book module or generated lesson.

These additions cover the two-stream premise, four members and correspondences, the four portraits, mixed types, appearance, extremes, diversity, educational routes, indirect self-education, social purpose and textual provenance. The full companion remains the place for the lecture’s complete argument and details; the combined course keeps a compact bridge into each essential theme.

The biological and historical analogy on capture 7 is represented as Steiner’s reasoning for individual continuity. Its reincarnation conclusion should not be presented as an empirical result established by behavioural observations. Likewise, the anaemia/illusion passage, eye-colour/body claims and historical psychiatric terms need source attribution. They should not be silently erased from the source account or carried over as the course’s diagnosis of its fictional person.

## Integration boundaries

`temperament-course.mjs` spreads a primary book lesson into each language object and then supplies original scenes, responses, practices and transfer questions. The source list and comparison summaries are read dynamically from companion modules. A change to a companion takeaway can therefore change a main comparison, including IDs whose primary book is another author. Root integration should review those generated comparisons and preserve the Childs/Mystery source claims.

Append the six proposed sections to the matching `temperamentTeaching` blocks, adapting their section representation for the existing renderer. Keep existing teaching at 2/3/5/7/8/9. Add the four `sourceChecks` alongside the current checks, preserving all case and transfer checks. Add the companion Lesson 01 reference at ID 0. The draft does not alter a case, original activity, transfer question or comparison claim.

This scoped review edited only this file and the machine-readable draft. It made no application changes, generated no site files, used no network source and ran no full-site checks. Verification consists of complete Markdown reading, direct review of the essential image columns and JSON/source-excerpt validation; integration and generated-page tests belong to the root task.
